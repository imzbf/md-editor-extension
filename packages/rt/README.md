# @vavt/rt-extension

Extension components for `md-editor-rt`. The v7-compatible release requires `md-editor-rt@^7.0.0`.

See the [component documentation](https://github.com/imzbf/md-editor-extension#vavtrt-extension).

In v7, `OriginalImg` needs an explicit raw HTML opt-in. `Mark` uses `markdown-it-mark` and works with `html: false`. Pass your editor's HTML sanitizer to `ExportPDF` as well.
