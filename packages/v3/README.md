# @vavt/v3-extension

Extension components for `md-editor-v3`. The v7-compatible release requires `md-editor-v3@^7.0.0`.

See the [component documentation](https://github.com/imzbf/md-editor-extension#vavtv3-extension).

In v7, `OriginalImg` needs an explicit raw HTML opt-in. `Mark` uses `markdown-it-mark` and works with `html: false`. Pass your editor's HTML sanitizer to `ExportPDF` as well.
